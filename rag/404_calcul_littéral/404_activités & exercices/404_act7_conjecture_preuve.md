# Partie A -- Un programme qui semble toujours revenir au départ {#partie-a-un-programme-qui-semble-toujours-revenir-au-départ .unnumbered}

::: tcolorbox
1.  Choisir un nombre.

2.  Le doubler.

3.  Ajouter $5$.

4.  Doubler le résultat.

5.  Retirer le triple du nombre de départ.

6.  Retirer $10$.
:::

1.  Applique le programme à $2$, $-3$ et $10$.

2.  Énonce une conjecture.

3.  Trois essais constituent-ils une preuve ?

::: tcolorbox
ıin 1,\...,7
:::

# Partie C -- Le programme trompeur {#partie-c-le-programme-trompeur .unnumbered}

::: tcolorbox
1.  Choisir un nombre.

2.  Ajouter $1$ à son carré.

3.  Multiplier par $6$.

4.  Retirer le cube du nombre de départ.

5.  Diviser par $11$.
:::

1.  Que pourrait-on conjecturer après les trois premiers essais ?
