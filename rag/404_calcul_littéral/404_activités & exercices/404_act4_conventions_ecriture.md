# Partie A -- Des écritures différentes {#partie-a-des-écritures-différentes .unnumbered}

Associe les écritures qui désignent le même nombre.

$$3\times x \qquad x+x+x \qquad 3x$$

$$x\times x \qquad x^2$$

$$1\times x \qquad x$$

$$x\times5 \qquad 5x$$

ıin 1,\...,4

# Partie B -- Conventions {#partie-b-conventions .unnumbered}

::: tcolorbox
On peut ne pas écrire le signe $\times$ devant une lettre ou une parenthèse :

$$3\times x=\dotfill
\qquad
5\times(x+2)=\dotfill$$

On écrit le nombre avant la lettre :

$$x\times7=\dotfill$$

On écrit :

$$x\times x=\dotfill
\qquad
1\times x=\dotfill$$
:::
