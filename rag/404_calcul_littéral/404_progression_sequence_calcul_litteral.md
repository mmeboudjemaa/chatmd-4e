# Objectifs de fin de séquence {#objectifs-de-fin-de-séquence .unnumbered}

L'élève doit pouvoir :

- traduire une phrase, une figure ou un programme par une expression littérale ;

- expliquer ce que représente une lettre ;

- calculer la valeur d'une expression pour une valeur donnée ;

- utiliser les conventions d'écriture du calcul littéral ;

- reconnaître la structure d'une expression : somme ou produit ;

- réduire une somme algébrique simple ;

- développer par distributivité simple, puis réduire si nécessaire ;

- distinguer une vérification sur quelques valeurs d'une preuve générale ;

- utiliser une expression réduite pour calculer plus efficacement.

# Automatismes {#automatismes .unnumbered}

Rituel de cinq minutes, quatre à six questions :

- séances 1 à 3 : traduire un programme et calculer une valeur ;

- séances 3 à 5 : simplifier une écriture et repérer les termes semblables ;

- séances 5 à 7 : réduire ;

- séances 6 à 8 : développer puis réduire ;

- après la séquence : une ou deux questions chaque semaine.

# Principes didactiques {#principes-didactiques .unnumbered}

- La lettre répond à une question portant sur **n'importe quelle valeur**.

- Plusieurs formules correctes sont conservées pour donner du sens à leur égalité.

- Tester une valeur peut aider à comprendre ou réfuter, mais ne prouve pas une identité.

- La technique vient après la situation, la verbalisation et l'écriture littérale.

- La résolution d'équations n'est pas l'objectif de cette séquence.
