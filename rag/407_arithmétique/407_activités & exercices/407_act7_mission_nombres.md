# Mission 1 -- Les nombres premiers {#mission-1-les-nombres-premiers .unnumbered}

Parmi les nombres suivants, recopie uniquement les nombres premiers :

$$51\qquad 53\qquad 57\qquad 61\qquad
67\qquad 69\qquad 71\qquad 77.$$

Pour chaque nombre écarté, donne un diviseur différent de $1$ et de lui-même.

Le premier chiffre du code est le nombre de nombres premiers trouvés.

::: tcolorbox
ıin 1,\...,5
:::

# Mission 2 -- Le nombre mystérieux {#mission-2-le-nombre-mystérieux .unnumbered}

Je suis un entier compris entre $100$ et $400$.

- Je suis pair.

- Je suis divisible par $11$.

- $3$ et $5$ sont aussi mes diviseurs.

Qui suis-je ? Justifie sans tester tous les entiers.

Le deuxième chiffre du code est mon chiffre des dizaines.

::: tcolorbox
ıin 1,\...,5
:::

# Mission 3 -- Décomposition {#mission-3-décomposition .unnumbered}

Décompose $396$ en produit de facteurs premiers.

Le troisième chiffre du code est le nombre total de facteurs premiers écrits dans la décomposition, en comptant les répétitions.

::: tcolorbox
ıin 1,\...,5
:::

# Mission 4 -- Fraction {#mission-4-fraction .unnumbered}

Simplifie :

$$\frac{84}{126}.$$

Le quatrième chiffre du code est le dénominateur de la fraction obtenue.

::: tcolorbox
ıin 1,\...,5
:::

# Mission 5 -- Vrai ou faux ? {#mission-5-vrai-ou-faux .unnumbered}

Pour chaque affirmation, réponds par vrai ou faux et justifie.

1.  Tout nombre impair est premier.

2.  Le seul nombre premier pair est $2$.

3.  Si un nombre est divisible par $6$, alors il est divisible par $3$.

4.  La somme de deux nombres premiers est toujours première.

5.  Un entier supérieur à $1$ peut toujours être décomposé en produit de facteurs premiers.

::: tcolorbox
ıin 1,\...,7
:::

# Bilan individuel {#bilan-individuel .unnumbered}

Rédige deux phrases :

1.  une méthode pour montrer qu'un nombre n'est pas premier ;

2.  une méthode pour simplifier une fraction à l'aide des facteurs premiers.

::: tcolorbox
ıin 1,\...,4
:::
