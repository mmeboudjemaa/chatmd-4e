# Partie A -- Deux chemins pour le nombre $84$ {#partie-a-deux-chemins-pour-le-nombre-84 .unnumbered}

Complète les deux arbres.

::::: center
::: minipage
$$84=\dotfill$$
:::

::: minipage
$$84=\dotfill$$
:::
:::::

1.  Les arbres sont-ils identiques ?

2.  Les facteurs premiers obtenus sont-ils les mêmes ?

3.  Dans quel ordre écrit-on habituellement les facteurs premiers ?

::: tcolorbox
ıin 1,\...,4
:::

# Partie B -- Construire une méthode {#partie-b-construire-une-méthode .unnumbered}

Remets les étapes dans l'ordre.

- Vérifier le produit obtenu.

- Choisir un diviseur premier du nombre.

- Continuer sur le quotient tant qu'il n'est pas premier.

- Écrire le nombre comme produit de facteurs premiers.

# Partie C -- Décomposer {#partie-c-décomposer .unnumbered}

Décompose chaque nombre en produit de facteurs premiers. Tu peux utiliser un arbre ou des divisions successives.

$$60\qquad 90\qquad 126\qquad 150\qquad 196$$

::: tcolorbox
ıin 1,\...,10
:::

# Partie D -- Vérifier et comparer {#partie-d-vérifier-et-comparer .unnumbered}

1.  Vérifie une décomposition en effectuant le produit.

2.  Quels facteurs premiers $60$ et $90$ ont-ils en commun ?

3.  Quels facteurs premiers $126$ et $196$ ont-ils en commun ?

4.  Une décomposition peut-elle contenir le nombre $1$ ? Justifie.

::: tcolorbox
ıin 1,\...,6
:::

::: tcolorbox
Décomposer un entier en produit de facteurs premiers consiste à l'écrire comme un produit ne contenant que des nombres premiers.

$$84=2\times2\times3\times7.$$
:::
