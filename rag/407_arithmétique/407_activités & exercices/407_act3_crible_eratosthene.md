# Partie A -- Appliquer l'algorithme {#partie-a-appliquer-lalgorithme .unnumbered}

Sur la grille :

1.  barre $1$ ;

2.  entoure $2$, puis barre tous ses multiples sauf $2$ ;

3.  entoure le plus petit nombre non barré ;

4.  barre tous ses multiples, sauf lui-même ;

5.  recommence jusqu'à ce que tous les nombres soient entourés ou barrés.

::: center
:::

# Partie B -- Comprendre l'algorithme {#partie-b-comprendre-lalgorithme .unnumbered}

1.  Pourquoi ne barre-t-on pas le nombre que l'on vient d'entourer ?

2.  Lorsqu'on barre un multiple de $5$, pourquoi sait-on qu'il n'est pas premier ?

3.  Certains nombres sont barrés plusieurs fois. Donne un exemple et explique pourquoi.

4.  Que représentent les nombres qui restent entourés ?
