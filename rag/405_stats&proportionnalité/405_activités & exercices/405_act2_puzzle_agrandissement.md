# Consigne commune {#consigne-commune .unnumbered}

Toutes les longueurs du puzzle doivent être multipliées par le même nombre.

- **Niveau 1 :** le segment de $4$ cm doit mesurer $2$ cm.

- **Niveau 2 :** le segment de $3$ cm doit mesurer $4{,}5$ cm.

- **Niveau 3 :** le segment de $5$ cm doit mesurer $7$ cm.

# Partie A -- Trouver le coefficient {#partie-a-trouver-le-coefficient .unnumbered}

Pour ton niveau, complète :

$$\text{nouvelle longueur}
=
\text{longueur du modèle}\times\ldots$$

Le nombre utilisé est appelé **coefficient d'agrandissement ou de réduction**.

::: tcolorbox
ıin 1,\...,3
:::
