# Checklist {#checklist .unnumbered}

::: tcolorbox
Avant de terminer, je vérifie :

- que mes effectifs ont le bon total ;

- que mes fréquences totalisent $100\%$ ;

- que ma série est rangée avant de chercher la médiane ;

- que j'ai pris les bonnes positions centrales ;

- que la moyenne possède la bonne unité ;

- que j'ai interprété l'indicateur dans le contexte ;

- que mon graphique comporte titre, légende et informations utiles.
:::
