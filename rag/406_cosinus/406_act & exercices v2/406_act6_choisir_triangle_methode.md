# Partie D -- Trois erreurs fréquentes {#partie-d-trois-erreurs-fréquentes .unnumbered}

Associe chaque erreur à une explication, puis corrige.

1.  $\cos(\widehat A)=\dfrac{\text{côté opposé}}{\text{hypoténuse}}$.

2.  Pour trouver une hypoténuse, on multiplie le côté adjacent par le cosinus.

3.  On arrondit $\cos(37^\circ)$ à $0{,}8$ avant de poursuivre le calcul.

Explications possibles :

- le résultat risque d'être trop imprécis ;

- la définition du cosinus n'utilise pas le côté opposé ;

- le résultat obtenu serait plus petit que le côté adjacent.
