# Partie B -- Mesurer et calculer {#partie-b-mesurer-et-calculer .unnumbered}

Pour les trois triangles de ta famille :

1.  mesure l'hypoténuse ;

2.  mesure le côté de l'angle droit qui touche l'angle étudié ;

3.  Calcule : $$\text{côté adjacent}\div\text{hypoténuse},$$ puis arrondis au centième.

# Partie C -- Conjecturer {#partie-c-conjecturer .unnumbered}

1.  Que remarques-tu dans une même famille ?

2.  Le nombre obtenu dépend-il de la taille du triangle ?

3.  Compare ce nombre avec celui des autres familles.

4.  De quoi ce nombre semble-t-il dépendre ?

# Partie D -- Utiliser la conjecture {#partie-d-utiliser-la-conjecture .unnumbered}

Dans une famille de triangles rectangles ayant un angle de $35^\circ$, le nombre obtenu est environ $0{,}82$.

1.  Si l'hypoténuse mesure $10$ cm, estime le côté adjacent.

2.  Si l'hypoténuse mesure $25$ cm, estime le côté adjacent.

3.  Retrouve la logique du calcul effectué.

::: tcolorbox
ıin 1,\...,7
:::
