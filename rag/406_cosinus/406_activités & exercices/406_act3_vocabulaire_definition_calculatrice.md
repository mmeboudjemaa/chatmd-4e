# Partie B -- Définition du cosinus {#partie-b-définition-du-cosinus .unnumbered}

Dans un triangle rectangle, pour un angle aigu donné :

$$\cos(\text{angle})
=
\text{côté adjacent}\div\text{hypoténuse}.$$

Complète dans le triangle précédent :

$$\cos(\widehat{A})
=
\ldots\div\ldots$$

$$\cos(\widehat{C})
=
\ldots\div\ldots$$
