# Partie A -- Un calcul que nous savons faire {#partie-a-un-calcul-que-nous-savons-faire .unnumbered}

Dans le triangle $GHI$ rectangle en $H$, on connaît :

$$GH=6\text{ cm}
\qquad\text{et}\qquad
HI=8\text{ cm}.$$

Calcule $GI$. Indique la propriété utilisée.

::: tcolorbox
ıin 1,\...,9
:::

# Partie B -- Le problème de la rampe {#partie-b-le-problème-de-la-rampe .unnumbered}

Une rampe rectiligne mesure $5$ m. Elle forme un angle de $28^\circ$ avec le sol horizontal.

On cherche la longueur au sol $AB$.

::: center
:::

1.  Le théorème de Pythagore permet-il de calculer $AB$ avec ces seules données ?

2.  Quelles informations connaît-on dans le triangle ?

3.  Quelle longueur cherche-t-on par rapport à l'angle de $28^\circ$ ?

4.  Propose une estimation raisonnable de $AB$, sans chercher une valeur précise.

::: tcolorbox
ıin 1,\...,4
:::

::: tcolorbox
ıin 1,\...,7
:::

# Partie C -- Un cas particulier accessible {#partie-c-un-cas-particulier-accessible .unnumbered}

Construis un triangle équilatéral de côté $10$ cm puis trace une hauteur.

Tu obtiens deux triangles rectangles possédant un angle de $60^\circ$.

1.  Quelle est la longueur de l'hypoténuse de l'un de ces triangles ?

2.  Quelle est la longueur du côté adjacent à l'angle de $60^\circ$ ?

3.  Par quel nombre faut-il multiplier l'hypoténuse pour obtenir ce côté adjacent ?

::: tcolorbox
ıin 1,\...,16
:::
